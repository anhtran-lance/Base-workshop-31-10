## Cách cộng tác
1. Tạo nhánh riêng: `feature/<tên-bạn>-<việc>`.
2. Sửa trong thư mục của web cần chỉnh, push nhánh.
3. Vercel tự tạo link xem thử cho nhánh; mở Pull Request để gộp vào `main`.
4. Chỉ gộp vào `main` sau khi PM duyệt.

Không commit mã truy cập, token hay khóa API.
